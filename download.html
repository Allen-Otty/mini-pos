Download Dogo POS

Install the app for faster start-up and reliable use with or without internet. Sales made offline sync when you reconnect.

Android

For phones and tablets (APK).

Download APK
  1. Open the downloaded file.
  2. If asked, allow installs from this source.
  3. Tap Install, then open Dogo POS.

Windows

For PCs and laptops (installer).

Download .exe
  1. Run Dogo-POS-Setup.exe.
  2. If Windows SmartScreen appears, choose More info → Run anyway.
  3. Follow the installer, then open Dogo POS.

Tip: you can also use Dogo POS in any browser with no download.
